# Spec 0005 implementation and verification plan

Spec 0004 is accepted. The initial working tree was clean. Its code and historical evidence are the baseline, including the accepted strict 60 Hz sampling limit and explicit Connect after timeout. No protocol or fixture change is planned.

Already implemented: source/session/sequence admission, A only mapping, latest state storage, separate output worker, timeout neutral/detach, sticky backend faults, lifecycle cleanup, wrapping sequences and drift avoiding sender scheduling. Existing tests cover the core paths.

Remaining slice: measured cadence and bounded status presentation, validated 100–1000 ms timeout configuration, categorized saturating local counters, prompt transition status, bounded asynchronous terminal writing, coordinated output task failure, deterministic fault injection and campaign instructions. No new runtime dependencies are needed.

Diagnostic policy: use the existing three second status silence deadline. At one second without admitted status, show degraded health. Status with no accepted state or an observed rate below 45 Hz is degraded. This is diagnostic UI policy only and does not change admission or reconnect. Echo age is wrapping client monotonic age, includes PC state age and scheduling, and is not a pure network RTT. Cadence statistics use successful scheduled send intervals, exclude cleanup sends, and publish at most twice per second. Local totals saturate; wire accepted/rejected totals wrap and loss saturates as specified.

Transitions are checked every 5 ms by transport, with best effort status sends. Counters are local and never added to the wire. Log output uses a bounded queue and drops on full/error; a blocked terminal must not block controller safety. Driver calls remain synchronous and cannot be cancelled by Tokio.

Automated verification uses fake time, recording backends and loopback UDP. Physical campaigns remain separately required: measured held A loss matrix, 30 minute phone/driver soak, 20 lifecycle cycles, 50 explicit reconnects and 20 Wi-Fi cycles. Compilation and simulation do not close those gates.
